# Screenshots / demo checklist — Claim Quest

The visible surface is **one entry in the FTB Quests task picker plus its
progress display** — both belong to the host GUI, so shots should make clear
what is ours (the task type) inside the host's own look.

## Candidate screenshots (pick 1–2)

1. **Quest editor, task added** — an FTB Quests chapter in edit mode with a
   **Claim Chunks** task selected and *Chunks to claim* set (e.g. `25`). Shows
   quest makers exactly where the feature lives.
2. **Progress in player view** — the same quest in the normal quest GUI showing
   partial progress (e.g. `2 / 25`) after a few claims, ideally next to the FTB
   Chunks map with the claimed area visible. Shows players what they get.

## How to stage it

- Single-player or local server with FTB Quests + FTB Chunks + FTB Teams +
  FTB Library and this mod.
- Create a quest, add the Claim Chunks task, set a low target (3–5) so one
  short claiming session reaches it.
- Claim chunks on the FTB Chunks map, reopen the quest GUI, capture the
  progress state.

## Do NOT screenshot

- Config files or "no config" claims as a feature shot.
- Any unclaim/reclaim sequence presented as progress loss — progress is a
  high-water mark by design; do not frame it as a bug.
- Other claim mods' UIs — only FTB Chunks claims are counted.
